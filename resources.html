Bayesian Analysis STAT40850 · UCD

Machine learning and AI including deep learning — implemented in R with keras and benchmarked on out-of-sample prediction.

Matrix theory — eigenvalues, matrix norms, Schur and singular value decompositions, conditioning and positive-definite matrices.

Data programming in Python — manipulation, visualisation, regression, classification, machine learning, APIs and web scraping.
